## ۲. اسکریپت اعتبارسنجی خودکار کامل فایل ایمپورت دیتابیس

کد پایتون زیر کیفیت کل ۱۴,۷۷۷ سطر استخراج‌شده از فایل مبدأ کارفرما را بررسی می‌کند:

```python
import csv

# اعتبارسنجی فایل کامل ایمپورت (۱۴,۷۷۷ سطر)
with open('source/dataset/generated/products_variants_full_2111.csv', mode='r', encoding='utf-8-sig') as f:
    reader = csv.DictReader(f)
    skus = set()
    slugs = set()
    total_rows = 0
    
    for row in reader:
        total_rows += 1
        # ۱. کنترل یکتایی SKU
        if row['SKU'] in skus:
            raise ValueError(f"کد SKU تکراری یافت شد: {row['SKU']}")
        skus.add(row['SKU'])
        
        # ۲. بررسی حد مجاز قیمت به تومان
        if int(row['Variant_Price_Toman']) < 50000:
            raise ValueError(f"قیمت غیرمجاز برای SKU: {row['SKU']}")

print(f"✅ کل {total_rows} متغیر (مربوط به ۲,۱۱۱ عطر فایل مبدأ) با موفقیت اعتبارسنجی شدند.")
```
