# تعویض منبع داده — از ۲٬۱۰۶ عطر ساختگی به ۲٬۱۱۱ عطر اصیل

**وضعیت:** زنده · مرداد ۱۴۰۵

این سند مرجع تعویض بنیادی منبع کاتالوگ است. اگر روزی منبع دوباره
عوض شد، از همین‌جا شروع کنید.

## چرا این کار لازم بود

منبع پیشین (`perfume-dataset-2000plus.md`) ایراد ریشه‌ای داشت:
بیشتر رکوردهایش نام‌های ساختگی بودند که از ترکیب تصادفی نام برند
با کلمات قالبی ساخته شده بودند.

نمونه‌های واقعی از فایل قدیمی:

```
PENHALIGON'S - Penhaligon's Absolu
PENHALIGON'S - Penhaligon's Sport / Fraiche
PENHALIGON'S - Cuir de Penhaligon's
PENHALIGON'S - Vanille Penhaligon's
PENHALIGON'S - Royal Rose Penhaligon's
```

هیچ‌کدام عطر واقعی نیستند. الگو آشکار است: نام برند + یک کلمه از
فهرست ثابت (`Absolu`، `Sport`، `Cuir de`، `Vanille`، `Oud`…).

**چرا خطرناک بود:** فروشگاهی که ۲٬۱۰۶ عطر جعلی فهرست کند، با
نخستین مشتری آگاه اعتبارش را از دست می‌دهد. در بازار عطر، مشتری
حرفه‌ای دقیقاً همان کسی است که بیشترین خرید را می‌کند.

## اعتبارسنجی منبع جدید — پیش از پذیرش

هیچ داده‌ای بدون سنجش وارد نشد. `import_dataset_v2.py --verify`
شش بررسی اجرا می‌کند:

```
✓ تعداد ردیف ۲۱۱۱ است
✓ شماره‌ها پیوسته و یکتا           ۱ تا ۲۱۱۱ بدون جاافتادگی
✓ هیچ سلول خالی نیست               ۰ خالی در ۵۷٬۰۰۰ سلول
✓ فرمول قیمت درست است              ۰ ناهماهنگ (تومان = دلار × ۲۰۰٬۰۰۰)
✓ سال عرضه قابل تجزیه است          ۰ نامعتبر
✓ هر ۸ خانواده سایت پوشش دارد
```

### 🔴 دامی که در شمارش افتادم

نخستین شمارش من **۹۹۹ ردیف** داد، نه ۲۱۱۱. علت: از ردیف ۱۰۰۰ به
بعد شماره‌ها با کاما نوشته شده‌اند (`| 2,111 |`) و الگوی
`^\|\s*\d+\s*\|` آن‌ها را نمی‌گرفت.

اگر همان‌جا نتیجه‌گیری می‌کردم، گزارش می‌دادم «فایل ناقص است» —
که کاملاً غلط بود. الگوی درست: `^\|\s*([\d,]+)\s*\|`.

### 🔴 کرانِ من غلط بود، نه داده

اعتبارسنجی یک ردیف را رد کرد: سال `1,533` برای
`SANTA MARIA NOVELLA - Acqua della Regina`.

بررسی نشان داد **داده درست است** — این عطر تاریخی کاترین دو مدیچی
است و از قدیمی‌ترین عطرهای ثبت‌شده جهان. رده‌اش در همان فایل «نیش
باستانی» است. کران پایین از ۱۷۰۰ به ۱۵۰۰ اصلاح شد.

## 🔴 مهم‌ترین تصمیم: قیمت‌گذاری

قیمت گرمی فایل، بهای **اسانس اورجینال** است، نه محصول دست‌ساز.

اعمال مستقیمش یعنی:

| | سمپل ۳ میل کرید اونتوس |
|---|---|
| قیمت فعلی سایت | حدود ۱۸۴٬۰۰۰ تومان |
| فرمول خام فایل | **۳٬۶۴۰٬۰۰۰ تومان** |

حدود **۲۰ برابر**. کل فروشگاه از دسترس مشتری خارج می‌شد.

**تصمیم مالک:** ضرایب قیمت‌گذاری فعلی دست‌نخورده بمانند، منتظر
فرمول اختصاصی.

نکته‌ای که کار را ساده کرد: قیمت‌های امروز سایت **از همین ضرایب**
روی قیمت گرمی منبع قدیمی آمده بودند. پس «حفظ قیمت فعلی» دقیقاً
یعنی «همان ضرایب روی قیمت گرمی منبع جدید» — کاملاً سازگار.

```python
سمپل ۳ml      = گرم × 0.12 + 40,000
ادوپرفیوم     = گرم × (حجم/10) × 0.35 + 150,000
عطر مو ۱۵۰ml  = گرم × 5  × 0.22 + 120,000
بادی ۱۵۰ml    = گرم × 10 × 0.12 + 100,000
```

قیمت دلاری خام در `variants.price_usd` ذخیره می‌شود. به مشتری
**نشت نمی‌کند** — `attachVariants()` فهرست سفید دارد.

## دو ستون تازه: عطار و سال عرضه

منبع جدید دو اطلاعات دارد که پیش‌تر نبود.

```sql
ALTER TABLE products ADD COLUMN perfumer     TEXT;
ALTER TABLE products ADD COLUMN release_year INTEGER;
```

**چرا نمایش داده می‌شوند:** این دو ادعای «کار تخصصی» را از حرف به
مدرک تبدیل می‌کنند. مشتری که می‌بیند «عطرساز: François Demachy ·
عرضه: ۲۰۱۵» می‌فهمد فروشنده می‌داند از چه حرف می‌زند.

در صفحه محصول جعبه‌ای با عنوان **«شناسنامه رایحه اصلی»** اضافه شد
که پس از هرم بویایی می‌آید. زیرش این جمله هست:

> این اطلاعات درباره **رایحه اصلی** است، نه محصول ما. بازآفرینی
> دست‌ساز عطر یزد بر پایه همین ساختار بویایی ساخته می‌شود.

بدون این جمله، نمایش نام عطرساز اورجینال می‌توانست ادعای ضمنی
اصالت تعبیر شود — دقیقاً چیزی که سیاست شفافیت برند رد می‌کند.

`perfumer` و `release_year` به `search_blob` هم اضافه شدند، پس
جستجوی «دماشی» یا «۱۹۵۹» نتیجه می‌دهد.

## نگاشت خانواده بویایی

منبع جدید **۱۶۴ ترکیب** دارد (`Woody Aromatic`، `Oriental Woody`،
`Chypre Floral`…) که باید به ۸ خانواده سایت نگاشته شوند.

### 🔴 چرا ترتیب بررسی حیاتی است

نسخه اول اسکریپت زنجیره `if` داشت که اول `woody` را می‌دید. نتیجه:
`Oriental Woody` (۲۸۴ عطر) و `Woody Aromatic` (۱۱۹ عطر) هر دو
«چوبی» می‌شدند و خانواده عنبری تقریباً خالی می‌ماند.

**راه‌حل:** واژه **نخست** رشته تعیین‌کننده است — در عطرشناسی
خانواده اصلی اول می‌آید و بقیه توصیف‌گرند.

### چرا `aquatic` ساخته نشد

سایت ۸ خانواده دارد و آبزی جزوشان نیست (نه تصویری، نه فیلتری).
منبع جدید فقط ۵ عطر آبزی دارد. ساختن خانواده نهم برای ۵ عطر یعنی
دسته‌ای تقریباً خالی با تصویر شکسته در ویترین.

آن پنج به `aromatic-fresh` رفتند — هر پنج در نام خامشان
`Aromatic` یا `Citrus` یا `Aldehydic` دارند.

## تصاویر — اشتراک درون خانواده

توزیع خانواده×جنسیت کاملاً عوض شد و ترکیب‌های تازه‌ای ظاهر شدند که
تصویر اختصاصی نداشتند:

```
ambery-oriental|WOMEN   ۲۰۱ محصول
citrus|MEN               ۴۶ محصول
chypre|WOMEN             ۴۱ محصول
leather|MEN              ۳۹ محصول
```

روی هم **۳۹۰ محصول (۱۸٫۵٪)** به تصویر تکیِ بی‌جنسیت می‌افتادند —
۱۷۴ محصول با یک عکس یکسان.

**راه‌حل:** اجازه اشتراک تصاویر **درون همان خانواده بویایی**، با
ترتیب بازگشت `جنسیت خودش ← یونیسکس ← هر جنسیت دیگر`.

دلیلش زیبایی‌شناسی نیست، دقت است: تصاویر بر پایه **نُت‌های
خانواده** ساخته شده‌اند و بطری‌ها بی‌نام و خنثی‌اند. یک بطری روی
بستر چوب سدر، برای عطر چوبی زنانه هم درست است.

| | پیش | پس |
|---|---|---|
| بزرگ‌ترین گروه هم‌تصویر | ۱۷۴ | **۱۰۲** |
| روی تصویر عمومی `family-*` | ۳۹۰ | **۰** |

## باگ واقعی که این تعویض آشکار کرد

`variantCampaignPercent` در `src/db.js` درصد مؤثر جشنواره را با
`Math.round` گرد می‌کرد. با قیمت‌های تازه این رخ داد:

```
قیمت ۵۷۰٬۰۰۰ · سقف جشنواره ۲۰٬۰۰۰
درصد خام: 20000/570000 = ۳٫۵۱٪
با round → ۴٪ → تخفیف ۲۲٬۸۰۰   ← ۲٬۸۰۰ تومان بیشتر از سقف!
با floor → ۳٪ → تخفیف ۱۷٬۱۰۰   ← داخل سقف ✓
```

**این ضرر مالی واقعی در هر فروش جشنواره‌ای بود.** با کاتالوگ پیشین
قیمت‌ها طوری بودند که هرگز رخ نمی‌داد.

اصلاح: `Math.floor`. درصد نمایشی ممکن است کمی کمتر از حداکثر ممکن
باشد، ولی هرگز بیشتر از چیزی که واقعاً می‌دهیم نیست.

## دستور بازتولید کامل

```bash
# ۱) اعتبارسنجی منبع (چیزی نمی‌نویسد)
python3 scripts/import_dataset_v2.py --verify

# ۲) ساخت seed
python3 scripts/import_dataset_v2.py

# ۳) گزارش پیش از تعویض
node scripts/replace_catalog.js --dry-run

# ۴) تعویض واقعی — داده تراکنشی حفظ می‌شود
node scripts/replace_catalog.js --yes

# ۵) بازتخصیص تصاویر
node scripts/reassign_images.js

# ۶) اصلاح نگارش فارسی
node scripts/fix_brand_names.js
node scripts/fix_duplicate_brand_in_name.js

# ۷) تأیید
bash scripts/smoke_test.sh
```
