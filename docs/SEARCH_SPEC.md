# مشخصات فنی موتور جستجوی داخلی و هوشمند (Internal Search Spec)
**پروژه:** فروشگاه آنلاین عطر یزد | Yazd Perfume  

با توجه به اینکه محصولات فروشگاه شامل اسامی انگلیسی، معادل‌های فارسی، کدهای کالا و نام‌های عمومی (مثل «اونتوس») هستند، موتور جستجوی داخلی بر اصل **"تحمل خطای تایپی، سرعت زیر ۵۰ms و فهم مترادف‌ها"** پیاده‌سازی می‌شود.

---

## ۱. نرمالسازی و اصلاح کاراکترهای فارسی/عربی (Character Normalization Rules)

قبل از ارسال هر عبارت به موتور جستجو، متن ورودی از فیلتر نرمالسازی زیر عبور می‌کند:

1. **تبدیل کاراکترهای عربی به فارسی:**
   - `ي` (عربی) ──> `ی` (فارسی)
   - `ك` (عربی) ──> `ک` (فارسی)
2. **مدیریت نیم‌فاصله (Zero-Width Non-Joiner - ZWNJ):**
   - تمامی نیم‌فاصله‌ها و فاصله‌های اضافه یکسان‌سازی می‌شوند (مثال: `دست‌ساز` ≡ `دست ساز` ≡ `دستساز`).
3. **حذف اعراب و تنوین:**
   - حذف کامل َ ُ ِ ً ٌ ٍ ّ ْ از عبارات جستجو.
4. **اعداد فارسی و انگلیسی:**
   - تبدیل اتوماتیک اعداد انگلیسی و عربی به عدد یکسان جهت لود محصولات (مثال: `540` ≡ `۵۴۰`).

---

## ۲. جدول مترادف‌های اختصاصی عطر (Perfume Synonym Dictionary)

موتور جستجو از یک فرهنگ واژگان مترادف (Synonym Index) جهت تطبیق نام‌های فارسی و انگلیسی استفاده می‌کند:

| عبارت ورودی کاربر | مترادف‌های نگاشت‌شده در جستجو |
|---|---|
| **اونتوس / اونتوز / کرید** | `Creed Aventus`, `کرید اونتوس`, `Aventus` |
| **باکارات / باکارات روژ** | `Baccarat Rouge 540`, `MFK`, `۵۴۰` |
| **توتون وانیل / تنباکو وانیل** | `Tom Ford Tobacco Vanille`, `تام فورد` |
| **ساواژ / ساوج / دیور** | `Dior Sauvage`, `دیور ساواژ` |
| **عطر مو** | `Hair Mist`, `هیر میست` |
| **بادی اسپلش** | `Body Splash`, `اسپری بدن` |
| **سمپل / دکانت / تست** | `3ml Sample`, `Decant`, `تست رایحه` |

## ۳. قابلیت تحمل خطای تایپی (Fuzzy Search & Typo Tolerance)

با استفاده از الگوریتم **Levenshtein Distance** (با حد مجاز فاصله ۲ کاراکتر):
- اگر کاربر تایپ کند `اونتث` ──> جستجو نتایج `اونتوس` را برمی‌گرداند.
- اگر کاربر تایپ کند `Bakarat` ──> جستجو نتایج `Baccarat` را برمی‌گرداند.
- اگر کاربر تایپ کند `باپارات` ──> سیستم پیشنهاد می‌دهد: *"آیا منظور شما باکارات روژ بود؟"*

## ۴. مشخصات جستجوی زنده در لحظه (Autocomplete Live Search)

1. **مکانیزم Debounce:** ارسال درخواست به API پس از تاخیر **۳۰۰ میلی‌ثانیه** از آخرین کلید تایپ‌شده کاربر جهت جلوگیری از ایجاد ترافیک زائد روی سرور.
2. **ساختار نتایج خروجی Dropdown:**
   - **بخش اول (محصولات پیشنهادی - حداکثر ۵ مورد):** شامل تصویر بندانگشتی، نام فارسی/انگلیسی و قیمت شروع از.
   - **بخش دوم (دسته‌بندی‌ها و برندها):** لینک مستقیم به برند (مثلاً: *"برند تام فورد"*).
   - **بخش سوم (عبارات کلیدی پرجستجو):** تکمیل خودکار عبارات.

---

## ۵. اولویت‌بندی نتایج (Search Result Scoring & Weighting)

امتیازدهی به نتایج جستجو بر اساس وزن‌دهی فیلدها انجام می‌شود:

$$\text{Total Score} = (\text{Title Match} \times 10) + (\text{Brand Match} \times 7) + (\text{Notes/Accords Match} \times 4) + (\text{Description Match} \times 1)$$

- **وزن ۱۰:** تطابق نام اصلی فارسی یا انگلیسی محصول.
- **وزن ۷:** تطابق برند الهام‌بخش.
- **وزن ۴:** تطابق نُت‌های بویایی یا آکوردها (مثال: اگر کاربر سرچ کند «عطر وانیلی»، تمام عطرهای دارای آکورد وانیل ظاهر می‌شوند).
- **وزن ۱:** تطابق متون بدنه توضیحات.
