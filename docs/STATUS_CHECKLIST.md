# وضعیت پروژه — ۲ نوامبر ۲۰۲۶

این برش مربوط به داده محلی است، نه گزارش سرور عملیاتی.

- فایل تأمین‌کننده ۳۴۲ ردیف و ۲۶۵ گروه نوشتاری قیمت دارد؛ ۲۶۵ محصول با قیمت موقت برای ساخت پس از سفارش فعال‌اند. گروه نوشتاری لزوماً رایحه یکتای تأییدشده نیست.
- هویت، نسخه و ترکیب اسانس واقعی تأمین‌کننده از منابع مرجع اثبات نشده است. ۱۱ گروه رایحه عمومی بدون برند مرجع‌اند.
- مهاجرت رزرو انبار پس از پشتیبان روی دیتابیس محلی اجرا و بازیابی آن بررسی شد؛ روی سرور واقعی اجرا نشده است. سفارش‌های قدیمی بدون سابقه رزرو حدسی بازسازی نمی‌شوند.
- سفارش‌ها، اقلام و مبالغ تاریخی باید حفظ شوند. **دستور حذف گروهی غیرفعال است** و هرگز برای پاک‌سازی داده موجود استفاده نشود.
- پشتیبان محلی مستقل بازیابی و آزموده شده؛ بازیابی پشتیبان سرور واقعی انجام نشده است. راهنما: `BACKUP_AND_RECOVERY.md` و `SQLITE_DELTA_BACKUP.md`.
- بررسی یکپارچه Node 22 و استقرار شبیه‌سازی‌شده موفق بوده‌اند؛ استقرار واقعی لیارا، پرداخت واقعی و پیامک واقعی هنوز انجام نشده‌اند. آزمون مرورگر عمومی در آخرین اجرای smoke به‌دلیل نبود Playwright رد نشد، بلکه اجرا نشد.
- برای تولید، رمز مدیر قوی، دیسک پایدار، دامنه، درگاه و پیامک باید جداگانه تنظیم و واقعاً آزمایش شوند. تنظیم محیط لزوماً رمز حساب مدیر موجود را بازنشانی نمی‌کند.
- برچسب‌ها و ادعاهای گرافیکی یا بویایی باید همچنان پیش از انتشار بررسی شوند؛ هیچ ادعای اورجینال بودن محصول دست‌ساز یا یکسانی اسانس مجاز نیست.

دستورهای آزمون ایزوله:

```bash
bash scripts/smoke_test.sh
bash scripts/test_node22_integration.sh
python3 scripts/test_destructive_tool_guards.py
```

استقرار واقعی و مهاجرت دیتابیس موجود بدون پشتیبان معتبر و بررسی وضعیت آن انجام نشود. جزئیات: `READY_TO_LAUNCH.md` و `DEPLOY_LIARA.md`.
