## دو گونه سند

فهمیدن این تفاوت مهم است، وگرنه سند گذشته را با وضعیت امروز
اشتباه می‌گیرید:

| گونه | نمونه | آیا به‌روز می‌شود؟ |
|---|---|---|
| **زنده** | `STATUS_CHECKLIST` · `API_REFERENCE` · `DATABASE_SCHEMA` · `FILE_INDEX` · `ARCHITECTURE` | بله — همیشه امروز را می‌گویند |
| **تاریخی** | `AUDIT_*` · `BENCHMARK_*` · `CHANGELOG_*` · `GAP_ANALYSIS` | خیر — عکس یک لحظه از گذشته |

سند تاریخی عمداً دست‌نخورده می‌ماند. اگر ممیزی تیر ماه را
به‌روز کنیم، دیگر نمی‌شود فهمید آن روز کجا بودیم.

دو ابزار این تفاوت را می‌شناسند و خودکار بررسی می‌کنند:

```bash
node scripts/audit_docs.js         # فایلی که سند نام برده هست؟
node scripts/audit_docs_truth.js   # عددی که سند ادعا کرده درست است؟
```

## بایگانی

`archive/docs-legacy/` — ۱۱ سند از دوران طراحی اولیه که درباره
**Vendure، MedusaJS و Next.js** بودند. هیچ‌کدام پیاده‌سازی نشد.

نگه داشته شدند تا تاریخچه تصمیم‌ها گم نشود، اما **برای کار با
سیستم فعلی به آن‌ها مراجعه نکنید**.
