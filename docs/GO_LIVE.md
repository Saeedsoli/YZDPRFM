# راهنمای فعال‌سازی درگاه پرداخت و پیامک

> **تاریخی:** برای وضعیت و دستورهای فعلی، `STATUS_CHECKLIST.md` و `BACKUP_AND_RECOVERY.md` را ببینید. هیچ حذف گروهی یا بازنویسی دیتابیس مجاز نیست.

هر دو سرویس **قابل‌تعویض** طراحی شده‌اند: با تنظیم چند متغیر محیطی فعال می‌شوند.
**هیچ تغییری در کد لازم نیست.**

---

## بخش ۱ — درگاه پرداخت زرین‌پال

### وضعیت فعلی
درگاه آزمایشی داخلی فعال است (`/payment/sandbox`). هیچ پول واقعی جابه‌جا نمی‌شود.

### پیش‌نیاز
- نماد اعتماد الکترونیکی (دارید ✓)
- ثبت‌نام در [zarinpal.com](https://zarinpal.com) و دریافت **Merchant ID**
- Merchant ID یک رشته ۳۶ کاراکتری است: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

### گام ۱ — تست با محیط آزمایشی زرین‌پال

```bash
liara env set PAYMENT_GATEWAY=zarinpal --app yazdperfume
liara env set ZARINPAL_MERCHANT_ID="شناسه-پذیرنده-شما" --app yazdperfume
liara env set ZARINPAL_SANDBOX=true --app yazdperfume
liara env set SITE_URL="https://yazdperfume.ir" --app yazdperfume
```

یک خرید آزمایشی انجام دهید. باید به صفحه زرین‌پال هدایت شوید.

### گام ۲ — فعال‌سازی واقعی

```bash
liara env set ZARINPAL_SANDBOX=false --app yazdperfume
```

### بررسی وضعیت

```bash
curl https://yazdperfume.ir/api/health
```

```json
{
  "payment_gateway": "ZARINPAL",
  "payment_live": true
}
```

### آدرس بازگشت (Callback)
در پنل زرین‌پال ثبت کنید:

```
https://yazdperfume.ir/payment/callback
```

### بازگشت به حالت آزمایشی

```bash
liara env set PAYMENT_GATEWAY=sandbox --app yazdperfume
```

## بخش ۲ — پیامک ورود (پیامیتو)

### وضعیت فعلی
`SMS_PROVIDER=console` — کد ورود در **لاگ سرور** چاپ می‌شود.
برای توسعه مناسب است، اما مشتری واقعی کد را دریافت نمی‌کند.

### گام ۱ — دریافت کلید از پیامیتو

سامانه پیامکی فروشگاه **پیامیتو** است (`payamito.com`) و خط
اختصاصی دارد. از پنل پیامیتو نیاز دارید به:

| مورد | توضیح |
|---|---|
| نشانی وب‌سرویس | `SMS_API_URL` |
| کلید وب‌سرویس | `SMS_API_KEY` |
| شماره خط اختصاصی | `SMS_SENDER` |

### گام ۲ — فعال‌سازی

```bash
liara env set SMS_PROVIDER=payamito --app yazdperfume
liara env set SMS_API_URL="نشانی-وب‌سرویس" --app yazdperfume
liara env set SMS_API_KEY="کلید-شما" --app yazdperfume
liara env set SMS_SENDER="شماره-خط" --app yazdperfume
```

> لایه پیامک (`src/sms.js`) مستقل از ارائه‌دهنده نوشته شده.
> `kavenegar` هم پشتیبانی می‌شود ولی سامانه این فروشگاه پیامیتوست.

### بررسی

```bash
curl https://yazdperfume.ir/api/health
```

```json
{ "sms_provider": "payamito" }
```

## سیاست‌های امنیتی پیاده‌شده

**رمز یکبار مصرف**
- ۵ رقمی، اعتبار ۲ دقیقه
- فاصله ارسال مجدد: ۶۰ ثانیه
- حداکثر ۵ تلاش نادرست، سپس ابطال کد
- نشست مشتری: ۳۰ روز

**پرداخت**
- مبلغ همیشه از دیتابیس محاسبه می‌شود، نه از ورودی کاربر
- تأیید دوباره یک سفارش مسدود است
- در صورت لغو یا خطا، موجودی خودکار بازمی‌گردد
- مبلغ ارسالی به زرین‌پال با مبلغ ثبت‌شده سفارش تطبیق داده می‌شود

## چک‌لیست پیش از افتتاح

### گام صفر — آزمون خودکار

```bash
bash scripts/smoke_test.sh
```

۱۰۰ بررسی: همه صفحات، ریدایرکت‌های ۳۰۱، sitemap، مسیرهای API،
آزمون‌های امنیتی، سفر خرید کامل، و **دو آزمون همزمانی**
(فروش آخرین موجودی · تأیید پرداخت تکراری · بازگشت تکراری از درگاه)،
آزمون پایداری کد ورود پس از ری‌استارت، اطلاع‌رسانی موجود شدن کالا، سقف
کد تخفیف، خنثی‌سازی تزریق اسکریپت، سامانه نقش‌ها، **آزمون ضد ارتقای
دسترسی** (۲۱ بررسی)، **کیفیت جستجو** (۱۸ بررسی)، **استقرار از صفر با
شبیه‌سازی دیسک Liara** (۱۴ بررسی)، **تحلیل و ویترین** (۲۲ بررسی)،
**مرورگر واقعی با Chromium** (۱۹ بررسی)، و ممیزی پوشش مجوزها.
**اگر حتی یک مورد fail شد، مستقر نکنید.**
